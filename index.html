Tentang TechStarter Day

TechStarter Day adalah kegiatan pengenalan dunia pengembangan web untuk mahasiswa baru Teknologi Informasi.

Tujuan Kegiatan

Peserta mengenal cara developer menyusun informasi, menggunakan tools, membaca error, membangun sesuatu secara bertahap.

Agenda

  1. Mengenal cara kerja halaman web
  2. Menyusun struktur HTML sematic
  3. Mencoba DevTools dan debugging
  4. Menyimpan checkpoint dengan Git

apa yang akan di pelajari?

  • Membaca struktur halaman sebagai developer.
  • Memilih teks berdasarkan makna konten.
  • Mendiagnosis link dan gambar yang gagal.
  • Menyimpan perkembangan project dengan Git.
